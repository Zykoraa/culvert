# Unmodified Linux engines

Xray-core 26.7.28: MPL-2.0, [exact source](https://github.com/XTLS/Xray-core/tree/v26.7.28).

sing-box 1.13.19: GPL-3.0-or-later; [exact corresponding source](https://github.com/SagerNet/sing-box/tree/v1.13.19), including upstream build instructions. This distribution ships the unmodified upstream binary. Culvert launches it as a separate process through its documented SOCKS and TUN interfaces. The full license accompanies it in sing-box.txt.

Archive and binary hashes are pinned in linux/engines.lock.json. No upstream engine source is modified by Culvert.
