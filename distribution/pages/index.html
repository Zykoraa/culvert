Connection and protection

Verification uses sampled connection checks. Network lock is a separate, optional setting that blocks ordinary outbound traffic subject to documented exceptions. It affects the whole PC; Culvert includes Restore normal internet for recovery.

Live destination records stay local. The app does not use a destination-geolocation service.

Windows installation

Windows asks for administrator access to install Culvert and run the tunnel host. Setup has no Windows Authenticode publisher certificate. Compare the download hash above before first installation; installed Culvert verifies signed update feeds and bundles.
